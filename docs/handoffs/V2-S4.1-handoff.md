## 交付结果

S4.1 开发已完成：

- 英文 byte/duration 规则可同时解析 `Max 10 MB and 10 minutes`，并避免把无上传语义的 UI 秒数误作音频时长。
- rejection classifier/observer 支持英文 `exceeds/limit/too large` 与 toast/snackbar/notification 的 text、childList、class/hidden/aria-hidden 变化；成功提示被排除；全局 toast 仅在单活跃任务下关联，多任务稳定歧义；retry 仍最多一次。
- 新增 `src/audio/compressed-decoder.js`：MP3 有界 frame iterator；M4A AAC-LC `moov`/sample-table demux；Dedicated Blob Worker 内 `AudioDecoder`；有界 PCM/queue；逐个 `AudioData.close()`；取消与复用清理。
- MP3 超限形成 `REENCODE_AUDIO`；AAC-LC M4A 格式墙/体积墙形成 `TRANSCODE_AUDIO`；允许且合规的原 File 保持 identity passthrough；时长墙优先 `AUDIO_DURATION_LIMIT_UNFIXABLE`。
- 最终 MP3 除签名/帧/bytes/时长/采样率/声道外，新增 local Blob Worker 的首/中/尾代表窗口真实解码验证。
- UI 文案区分“重新编码 MP3”“将 M4A 转为 MP3”，时长错误明确“不裁剪/分段”。
- 新增 ADR-006、真实能力页、codec matrix、negative matrix、大文件/取消复用测试；既有 WAV planner 行为和 frozen lamejs encoder 保留。
