## 8. 更新检查

每次阶段交接前：

- 不允许 Must 行的代码/测试/证据只写“同上”；
- 路径必须真实存在，测试名必须可搜索；
- 一条证据可以支持多行，但每行写精确 JSON 字段或截图说明；
- `ACCEPTED` 只能由独立验收方填写；
- `NOT_APPLICABLE` 必须给 PRD/ADR 依据；
- 若 requirement 被 ADR 修改，同时保留原行和新行/注释，不能静默删除。
