# ADR-001：工程输出目录使用 main

- 日期：2026-08-17
- 状态：已决定
- 决策人：用户

## 背景

任务书的默认目标目录写为 `C:\Users\蔡天乐\Desktop\黑客松\uploadfit`，用户明确要求工程内容输出到 `C:\Users\蔡天乐\Desktop\黑客松\main`。

## 决定

本项目统一使用：

```text
C:\Users\蔡天乐\Desktop\黑客松\main
```

任务书中出现的 `uploadfit/`、`C:\Users\蔡天乐\Desktop\黑客松\uploadfit` 均按本 ADR 映射到 `main/`。不创建或写入另一个 `uploadfit` 工程目录。

## 影响

- 所有源码、测试、文档、证据和构建产物均位于 `main`。
- 交接文档中会明确记录该目录映射。
- 任务书中的目录结构和文件所有权仍然适用，仅根目录名称按本 ADR 替换。

## 回滚

只有用户明确要求更换工程根目录时，才新增迁移 ADR；不得自行复制或移动整个工程，以免产生两套不一致的代码和证据。
