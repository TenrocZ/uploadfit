# 70 S6：发布材料与演示交付

## 1. 阶段使命

把已经通过 S5 的代码变成评委可安装、可测试、可理解、可复查的完整比赛交付。S6 负责材料和发布，不负责用文案掩盖功能缺陷。

## 2. 前置条件

- S5 handoff 为 `READY_FOR_ACCEPTANCE`。
- E01–E15、Tabbit 实机、安全、性能、体积全部达标。
- 无 P0/P1/P2 未解决缺陷。
- 已获得发布测试页、生成安装链接和上传比赛材料所需授权。

如果缺少外部账号/权限，先完成本地材料并以 `BLOCKED` 交接，列出需要用户执行的最小步骤；不得伪造链接或声称已发布。

## 3. 文件范围

- 根 `README.md`。
- `docs/index.html`。
- `docs/demo-script.md`。
- `docs/test-results.md` 的最终环境/链接更新。
- `docs/release-checklist.md`、`docs/submission-manifest.md`。
- `dist/uploadfit.js` 及必要安装说明。
- `docs/evidence/S6/*`、`docs/handoffs/S6-handoff.md`。

除修复发布阻塞外不改业务源码。任何源码修复都必须返回 S5 跑完整回归，并更新证据/hash。

## 5. 生产构建

从干净 checkout 执行：

```powershell
npm ci
npm run check
npm run test:e2e
npm run build
(Get-Item -LiteralPath .\dist\uploadfit.js).Length
Get-FileHash -Algorithm SHA256 -LiteralPath .\dist\uploadfit.js
```

记录：

- Git commit。
- Node/npm 版本。
- 构建时间。
- 文件字节数和 SHA-256。
- `npm ls --omit=dev` 结果；运行时不应依赖外部包加载。
- 生产构建与 S5 验收构建是否同一 hash；不同则必须重跑 S5。

禁止手工改 `dist/uploadfit.js`。最终产物只能由构建生成。

## 8. 稳定测试页发布

- 公开 HTTPS 地址可无需登录访问。
- 首页直接列出场景 A–F 和操作说明。
- 使用仓库非敏感 fixtures 或浏览器生成样本。
- 不接收/存储用户上传，测试逻辑只在浏览器本地。
- 页面能显示版本号，并与最终脚本兼容。
- 发布后重新跑至少 E01、E03、E08、E10、E11、E15。

发布是外部状态变更，必须使用用户授权的托管目标；不擅自选择付费服务、绑定域名或公开私有仓库。

## 9. 安装包验收

在干净 Tabbit 环境：

1. 点击安装链接。
2. 不复制代码、不打开开发者控制台。
3. 打开公开测试页，手动运行。
4. 状态胶囊、场景 A/B/C/D/E/F 正常。
5. 关闭后无残留；刷新后需按脚本生命周期重新运行。
6. 不依赖 localhost 或开发机文件。
7. 更新/重新安装路径清晰。

记录完整 Tabbit 版本、安装链接、脚本版本/hash、日期、截图或短视频。

## 10. 三分钟演示

`docs/demo-script.md` 固定时长目标 2:45–2:55，绝不超过 3:00。

### 0:00–0:20 问题

真实规则 JPG、30–120KB、390×567 与约2.8MB PNG；说明用户当前多工具反复试错。

### 0:20–0:45 真实网页理解

打开公开官方说明页，运行脚本，展示规则卡和一次真实 Tabbit AI 候选；强调确定性代码校验。

### 0:45–1:35 预检适配

场景 A：展示当前文件、规则、动作、本地处理、390×567/合规字节 JPEG 回填。明确文件未发给第三方。

### 1:35–2:15 拒收兜底

场景 B：初始规则不足，明确错误出现，处理并重新分发一次，页面接受。画面显示 retry=1。

### 2:15–2:35 安全

快速展示裁剪必须确认和模糊错误不处理；展示表单按钮未被自动点击。

### 2:35–2:55 总结

回到价值、范围和浏览器安全边界。不要在结尾引入未演示的新承诺。

录制要求：

- 使用最终安装包和公开页面，不用开发分支/mock。
- 画面可读，隐去个人路径、账号、通知和敏感信息。
- 不剪掉关键等待来伪造时延。
- 旁白与界面结果一致。

## 12. 阶段退出标准

- 干净构建、测试和最终 hash 已记录。
- 安装、说明、测试、视频、源码/代码说明链接均有效且非 localhost。
- 干净 Tabbit 从安装链接完成关键流程。
- 视频≤180秒，展示真实页面理解、预检、明确拒收、确认和模糊错误边界。
- README、说明页、测试结果和 manifest 无互相冲突的版本/数据。
- 无密钥、个人路径、账号、真实敏感图片或未脱敏日志泄露。
- 最终交付与 S5 验收代码同一 commit/hash；否则已完整重测。
- `docs/release-checklist.md` 全勾选，handoff 状态为 `READY_FOR_ACCEPTANCE`。
